# ChatGPT へ：カード画像の作り方（WORD GRIMOIRE）

このリポジトリは英単語カードゲームです。カードの絵を、次の手順で作って GitHub に置いてください。
取り込み・変換・登録はリポジトリの管理者（Claude）が行います。**あなたは描いて置くところまで**です。

## 手順
1. **main** ブランチの `gpt_tasks/next/LIST.md` を開き、次に描く5枚（単語・保存するファイル名・プロンプトのファイル）を確かめる。
   ユーザーに、5つの単語名をそのまま伝える。
2. 1枚ずつ、`gpt_tasks/next/` の**そのカードのプロンプトのファイルを開き、中の英文をそのまま使って**描く。
   - **英文の全文は返事に書き出さない**（長いので）。描く前に、英文の中の `Scene:` の1文だけを返事に書く
     （正しいファイルを開いた目印。例：`Scene: The harpies dive at terrible speed over the cliffs.`）
   - 英文は、描くときには全部そのまま使う（短くしない・要約しない・言い換えない・足さない）
   - **単語の名前やイメージだけから描かない。** 英文の Scene に書かれた人物・生きもの・場所・動作を描く
   - ほかのカードの人物・動物・場所を持ち込まない（前のカードからも、後ろのカードからも）
   - 1枚の画像に1枚の絵。何枚分もの絵を並べない（格子・コラージュにしない）
   - 3:2 の横長（1536x1024）。文字・ロゴ・枠を入れない
3. 描いた画像を **`gpt-images` ブランチ**の **`incoming/単語.png`** に保存して push する（例：`incoming/speed.png`）。
   - ブランチが無ければ main から作る。あれば、そのまま足していく（古い画像は消さなくてよい）
   - **画像はバイナリの PNG のまま保存する。** 文字（base64）に書き換えたテキストファイルにしない
   - ファイル名は単語名の小文字だけ（`01_` などの番号は付けない）
   - **main ブランチと、`incoming/` 以外のファイルは変更しない**
4. 返事は短くする。1枚ごとに「単語名・Scene の1文・保存したファイル名」だけでよい。
5. 5枚そろったら、ユーザーに「保存した5つのファイル名と、それぞれの大きさ（KB）」を伝える。
   保存できなかったものがあれば、正直にそう伝える。

## してはいけないこと
- main ブランチへの push、プルリクエストの作成・マージ
- `gpt_tasks/` や `js/`・`assets/` など、`incoming/` 以外のファイルの変更
- 蜘蛛を描くこと（プロンプトに無くても足さない）
